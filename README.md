# IA Sem Mistério

Operação automatizada do canal (Instagram @iasemmisterio.ai e YouTube).

- `canal/rotina.md`: grade, regras e passo a passo de cada rodada (fonte da verdade).
- `canal/roteiros/`: um JSON por vídeo. `canal/validar.py` barra o que foge das regras; `canal/publicar.py` agenda no Buffer (e no Metricool quando precisa de primeiro comentário).
- `kit/`: kit visual Raio-X (motion, voz e render quadro a quadro).
- `videos/`: MP4 finais, usados como link de mídia no agendamento.
